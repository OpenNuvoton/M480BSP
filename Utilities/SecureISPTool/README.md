# SecureISPTool

`SecureISPTool.exe` is used with the Secure ISP sample code in:

```text
BSP\SampleCode\SecureBoot_LD\SecureISP
```

## Runtime Requirement

To execute `SecureISPTool.exe`, install Microsoft Visual C++ 2012 Redistributable
for both platforms:

- Visual C++ 2012 Redistributable (x86)
- Visual C++ 2012 Redistributable (x64)
